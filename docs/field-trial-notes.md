# 一周交接场景自测笔记

基于 `scripts/field-trial.sh`（保姆纸表文本 → 拍本草稿 → 确认入库 → 周 PDF）。

## 结果

- 连续 7 天拍本解析与入库全部通过（每天 6 行草稿，约 9 条事件）。
- 睡眠行不再与喂养行重复入库。
- 日/周 PDF、CSV、纸表 HTML、相册上传链路可用。

## 摩擦点与已回修

1. **睡眠重复行**：原先 `14:00-15:30 小睡` 会多出一条空喂养草稿 → 解析优先识别睡眠区间。
2. **交接信息缺失**：A4 日表底部增加「交接备注」栏；保姆说明同步更新。
3. **PDF 中文缺字**：服务端优先加载 `DroidSansFallback` / 文泉驿；Docker 镜像安装 `fonts-droid-fallback`。
4. **无云 OCR 时**：支持粘贴转写文本；纯拍照走示例草稿，强制人工核对（符合「草稿必确认」策略）。

## 建议试用流程（给家里）

1. 打印 A4 日表 7 张 + 保姆说明 1 张。
2. 保姆只填纸；家长每晚「拍本」粘贴/拍照 → 核对 → 入库。
3. 周末导出周 PDF 发给家人或儿保备用。
